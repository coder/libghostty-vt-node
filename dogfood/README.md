# Dogfood Proof Bundle

`dogfood/bootstrap/` records the commands and local outputs from the repository bootstrap. The bundle is intentionally plain text so a reviewer can inspect what was attempted without reproducing the environment first.

Expected files:

- `commands.sh`
- `environment.txt`
- `native-info.json`
- `smoke-output.txt`
- `test-output.txt`
- `npm-pack-output.txt`
- optional terminal recording or screenshot when local tooling is available
